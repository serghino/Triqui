# Triqui

Triqui is a simple implementation of the classic Tic-Tac-Toe game using React. The purpose of the game is to provide an interactive way for two players to compete by marking spaces in a 3×3 grid. The first player to align three of their marks horizontally, vertically, or diagonally wins the game. The app also tracks scores, supports draws, and allows resetting the board and scores.

## Features
- Two-player mode
- Score tracking and persistence
- Draw detection
- Easy reset options

## Purpose
This project demonstrates basic React concepts, state management, and user interaction in a fun and familiar game format. It is ideal for learning, practicing, or simply enjoying a quick game of Triqui (Tic-Tac-Toe).
